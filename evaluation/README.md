# evaluation/ — качество оценщика (Участники 2 и 4)

## Тест-сет с известными ответами
`data/testsets/synthetic_v1.json` — 8 сценариев × RU/KZ/EN = 24 диалога, 72 эталонных ответа по ДЕМО-чек-листу.
Собирается скриптом `evaluation/datasets/build_synthetic.py` из фраз, поэтому ответ однозначен по построению:
хороший диалог, приветствие только от бота, приветствие только от клиента, нет следующего шага,
вопрос решён (N/A), грубый оператор, инъекция в тексте клиента, оператор не уточнил суть.
Спорные критерии в сценариях НЕ размечены. Это не реальные данные и не замена эталонам по официальному чек-листу.

## Прогон и отчёт
```bash
.venv/bin/python evaluation/run_eval.py --tag base --calibration off --repeat 2
```
- работает в отдельной БД `data/eval.sqlite3` (рабочие оценки и калибровка не затрагиваются);
- отчёт `evaluation/reports/<tag>.md` (+ `.json` со всеми ответами): совпадение по критериям / языкам / сценариям,
  попадание доказательства в нужную реплику оператора, стабильность между повторами, стоимость, время;
- при исчерпании квоты прогон останавливается; досчитать позже: `--tag base --resume`.

## «Дообучение» = калибровка на решениях проверяющего
Веса модели не меняются: для 24-часового хакатона и без размеченных данных по официальному чек-листу это
не обосновано. Вместо этого каждое **изменение** оценки проверяющим в апелляции сохраняется как прецедент
(`calibration_examples`) и подставляется в промпт следующих оценок по тому же критерию:
- только если формулировка критерия не менялась (отпечаток критерия);
- никогда — из того же диалога, что оценивается (нет утечки ответа);
- не больше `LLM_CALIBRATION_PER_CRITERION` на критерий; версия промпта получает суффикс `+calN`;
- просмотр и выключение примеров: `GET /api/calibration`, `PATCH /api/calibration/{id}` `{"active": false}`.

Эффект измеряется тем же прогонщиком: ошибки базовой линии на одном языке → прецеденты → проверка на других:
```bash
.venv/bin/python evaluation/run_eval.py --tag cal --calibration on --seed-from base --seed-langs RU --langs KZ,EN
```
Сравнивать с `base` только на тех же языках. Перенос между языками одного сценария — это проверка
«похожего случая», а не независимый holdout.
