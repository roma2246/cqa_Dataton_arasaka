# evaluation/ — эталоны и приёмка (Участник 4)

- `golden/` — ручная эталонная разметка (Q04): один JSON на диалог в формате `CriterionResult[]`
  + поля `checklist_version`, `content_hash`, `split: dev|holdout`.
- `holdout` не использовать для подбора промпта (A04/A07). Переводы одного сценария RU/KZ держать в одном split.
- `compare.py` (сделать) — сравнение ИСХОДНЫХ ответов ИИ с эталоном: совпадение по критериям и языкам,
  precision/recall N/A, доля верных доказательств, ошибка итога. Решения проверяющего в метрику не входят.
- `acceptance.md` — чек-лист приёмки Q06 (таблица из TEAM_TASKS.md, с отметками и датой).
